# 🎬 MovieQuiz

Мобильное iOS-приложение с квизами о фильмах из **топ-250** и списка самых популярных фильмов IMDb.  
Игрок отвечает на вопросы о рейтингах фильмов, а цель игры — правильно ответить на все 10 вопросов раунда.  

[📡 IMDb API](https://imdb-api.com/api#Top250Movies-header)  
[🔤 Шрифты проекта](https://code.s3.yandex.net/Mobile/iOS/Fonts/MovieQuizFonts.zip)  

---

## 🚀 Технологии

- **Язык:** Swift 5.x  
- **Фреймворк:** UIKit  
- **Минимальная iOS:** 15.0  
- **Ориентация:** только портретная  
- **API:** IMDb (топ-250 и популярные фильмы)  
- **UI:** кастомные шрифты + макет Figma  

---

## ✨ Основные возможности

- 📱 Квиз из 10 вопросов о фильмах  
- 🖼️ Вопросы с постером фильма и вариантами «Да/Нет»  
- 🎯 Проверка ответа с подсветкой рамки изображения (зелёная/красная)  
- ⏱️ Автоматический переход к следующему вопросу через 1 секунду  
- 📊 Статистика по завершении раунда:  
  - Результат текущего раунда  
  - Количество сыгранных квизов  
  - Рекорд (лучший результат + дата/время)  
  - Средняя точность (%)  
- 🔄 Возможность сыграть снова  
- ⚠️ Обработка ошибок сети с алертом и кнопкой «Повторить»  

---

## 📱 Основные экраны

### 🚀 Сплеш-скрин
- Кратковременный экран загрузки при запуске приложения  

### ❓ Экран вопроса
- Постер фильма  
- Вопрос вида: *«Рейтинг этого фильма больше 6?»*  
- Кнопки «Да» / «Нет»  
- Проверка ответа с подсветкой рамки изображения  

### 🏆 Экран статистики (алерт)
- Результат текущего раунда  
- Количество сыгранных игр  
- Рекорд (лучший результат с датой и временем)  
- Средняя точность (%)  
- Кнопка «Сыграть ещё раз»
